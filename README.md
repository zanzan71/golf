# Visuels Instagram ELAZYO

Ce dépôt sert d'étagère publique aux visuels validés d'ELAZYO.
Metricool vient y chercher les images au moment de programmer un post Instagram.

- `instagram/` : un dossier par post, les slides dans l'ordre de publication.
- Rien d'autre n'y est déposé : pas de vidéo brute, pas de visuel non validé.

Ne pas supprimer un dossier tant que son post n'est pas publié.
